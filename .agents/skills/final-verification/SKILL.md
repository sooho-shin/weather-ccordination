# Final Verification (최종 검증 스킬)

## 1. 적용 조건

코드 수정, UI 변경, 데이터 패치, 하네스 업데이트 등 일체의 변경 작업이 완료된 후, 사용자에게 최종 보고를 남기기 직전에 반드시 실행한다.

---

## 2. 필수 검증 체크리스트

### ① 통합 하네스 실행 및 결과 레포트 확인
```bash
python3 scripts/run_harness.py
```
- 모든 스테이지(TypeScript 검증, 도메인 유닛 테스트, AC 일치성)가 `PASS`여야 합니다.
- `docs/reports/verification-report.json`이 갱신되었는지 확인합니다.

### ② 개발 포트 잔존 여부 확인 (Strict Rule)
브라우저 확인이나 로컬 테스트를 위해 실행했던 개발 서버 포트가 열려 있는지 확인하고 완전히 종료합니다.

```bash
# 열려있는 포트 확인 및 강제 종료
lsof -nP -iTCP:8081 -sTCP:LISTEN 2>/dev/null && lsof -ti :8081 | xargs kill -9 2>/dev/null || true
```

### ③ Git 상태 및 한글 커밋 확인
```bash
git status
```
- 의도치 않은 임시 파일이 스테이징되지 않았는지 확인합니다.
- 변경 사항이 커밋될 때 커밋 메시지는 100% 한글이어야 합니다.

---

## 3. 사용자 보고 양식

최종 응답 시 다음 3가지 사항을 명시적으로 요약 보고합니다:
1. **하네스 검증 결과**: 전체 통과 여부 및 테스트 개수
2. **포트 정리 상태**: 포트(8081 등) 정상 종료 확인
3. **Git 커밋 상태**: 한글 커밋 메시지 내용
